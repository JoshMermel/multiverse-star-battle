How to Play

Place stars on the boards so that:

  • Every row contains exactly one star.
  • Every column contains exactly one star.
  • Every bold region contains exactly one star.
  • Stars cannot touch each other, even diagonally.

Both boards share the same rows and columns, so a star placed on one board satisfies that row and column for both.

Controls

  • Left click — cycle empty → dot → star
  • Right click — toggle star directly
  • Click and drag — paint dots across multiple cells
