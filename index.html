How to Play

Place exactly 1 star per row, column, and bold region on each board. Stars cannot touch each other, even diagonally.

The boards always match — changes to one board automatically take effect on all other boards too.

Controls

  • Click — cycle empty → dot → star
  • Right-click — toggle star directly
  • Click and drag — paint dots across cells

Navigation

Use the Book button in the top bar to browse available puzzle collections — each book shows a description to help you choose.

Use the Browse Puzzles button to see progress on the current book.

Settings

Use the gear icon to edit settings like dark mode and timer visibility.
